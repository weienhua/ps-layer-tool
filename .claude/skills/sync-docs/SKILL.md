# Sync Docs

代码变更后，检查 `CLAUDE.md`、`AGENTS.md` 和 `doc/使用文档.md`（如存在）是否需要更新，只做必要的修改。

## 检查清单

### 项目结构
- 新增/删除的文件是否反映在文档的项目结构中？
- `src/components/`、`src/composables/`、`src/lib/` 等目录下的新文件是否列出？

### 宿主函数表
- `$.HostScript` 注册的函数列表是否完整？
- 函数说明是否准确？

### 类型声明
- `src/types/index.ts` 中的类型是否在文档中列出？
- 类型名变更（如字段重命名）是否同步？

### 面板 UI 描述
- 组件功能描述是否与当前实现一致？
- 核心流程是否反映最新架构？

### 存储 / localStorage key
- 文档中的 key 名称是否与实际代码一致？
- 已废弃的 key 是否移除？

### 构建配置
- webpack/config 变更是否反映在文档中？

### 常见问题排查
- 新增的已知问题是否加入 FAQ？
- 已修复的问题是否更新或移除？

### 使用文档（`doc/使用文档.md`）
仅在文件存在时检查，不存在则跳过：
- 新增的用户可见功能是否写入文档？
- 移除/变更的功能是否更新？
- UI 交互变化（新增按钮、开关、面板）是否反映？

## 执行流程

1. `git diff HEAD --stat` 查看变更文件列表
2. 对每个变更类别匹配上述检查清单
3. 逐一读取文档中相关段落，对比代码实际情况
4. 仅修改过时/缺失的内容，保留正确的部分
5. 不添加冗长描述，保持文档简洁

## 原则

- **最小修改**：只改确实过时的内容，不重构文档结构
- **事实驱动**：以代码实际状态为准，不推测
- **两端同步**：CLAUDE.md 和 AGENTS.md 如有重叠内容需同时更新
