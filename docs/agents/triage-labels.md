# 分诊标签

技能使用五个规范的分诊角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签名称。

| mattpocock/skills 中的标签 | 我们的标签 | 含义 |
| -------------------------- | ---------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待提交者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分明确，可由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不做处理 |

当技能提到某个角色时（例如"应用 AFK-ready 分诊标签"），请使用此表中对应的标签字符串。

如需自定义标签词汇，编辑右侧列即可。
